| Existing Alternative | Focus Area | Interface / Accessibility | Why you couldn't just contribute to it? (Justification for building TheHER) |
| :--- | :--- | :--- | :--- |
| **DearEIS** | EIS (Impedance) Fitting & Equivalent Circuits | Desktop GUI & Python API | DearEIS is strictly focused on **Impedance Spectroscopy (AC techniques)**. TheHER is focused on **Polarization Curves (DC techniques)** and specific HER kinetic mechanisms (Volmer-Heyrovsky-Tafel). Adding full LSV kinetic fitting to DearEIS would be out of scope for their project. |
| **ElectroKitty** | HER/OER Kinetic Mechanism Modeling | Python Package (Requires Coding) | While ElectroKitty models HER kinetics, it requires the user to write Python code. TheHER was built to provide a **zero-code, point-and-click web interface**, making it accessible to students and experimentalists with no programming background. |
| **MADAP** | General Electrochemical Voltammetry & EIS | Python Package (Requires Coding) | MADAP is a broad tool for generic voltammetry. TheHER is highly specialized: it simultaneously calculates surface hydrogen coverage ($\theta_H$) and rolling Tafel slopes alongside the fit, which is a niche workflow that wouldn't fit neatly into a general-purpose library. |
| **impedance.py** | EIS Analysis | Python Package (Requires Coding) | Completely out of scope. It handles EIS equivalent circuits, not DC polarization curve fitting. |
| **Bill Linch's Web Tool** | General Tafel Analysis (Fuel Cells) | Web Application | It only performs basic linear Tafel extraction ($i_0$ and $\alpha$). TheHER solves non-linear kinetic equations for multi-step mechanisms (Volmer-Heyrovsky-Tafel), which is mathematically much more complex. |
| **TafFit** | Tafel Data Fitting | Excel Macro (Requires Microsoft Excel & Solver) | TafFit is a great tool for objective Tafel fitting, but it is restricted to the Microsoft Excel ecosystem and requires enabling VBA macros. TheHER is a completely independent **web application** and additionally solves non-linear kinetic equations for full multi-step mechanisms (Volmer-Heyrovsky-Tafel). |
