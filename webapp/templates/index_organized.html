  1. Upload Data: Load your LSV data (.txt, .csv) or pick an example dataset. Set the delimiter and temperature.
  2. Set Window (Optional): Fit over the entire potential window first, then use Potential Min/Max to exclude very high potentials or onset values if needed.
  3. Corrections: Ensure the geometric area, ohmic drop ($R_u$), reference potential, and pH are accurately provided.
  4. Choose Model: Select the kinetic mechanism (Volmer-Heyrovsky, Volmer-Tafel, or full). Start with Bounded least squares.
  5. Advanced Search (Optional): If the fit does not converge, try checking Use global search before local refinement.
  6. Analyze: Click Run Kinetic Fitting & Analysis to view the Polarization fit, Surface Coverage ($\theta_H$), and Tafel Slope plots.
